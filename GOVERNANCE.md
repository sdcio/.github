# Governance stub

The SDC project is governed by the [maintainers](https://github.com/sdcio/.project/blob/main/maintainers.yaml) of the
project. Maintainers are nominated by other maintainers based on their activity in the project. 

As part of the CNCF Scandbox onboarding of SDC we plan to introduce a written governance, this file is the stup for it.
